# Familiar Sheet Evidence

**Tool ID:** `content.familiars.data` · **Section:** Familiars

## Purpose

Inspect explicit, hash-validated fields from supported XBM familiar sheets.

## Inputs

- **Familiar sheet:** XBMPet, XBMItem, or XBMContent.
- **Language:** Client, English, Japanese, German, or French.
- **Row ID:** numeric row identifier.

## Use

Choose sheet and language, enter row ID, then press **Capture**.

## Limits

Raw columns/unknown labels are not interpreted as stats, ownership, or roster membership. No familiar job required; no roster traversal or semantic decoding.
