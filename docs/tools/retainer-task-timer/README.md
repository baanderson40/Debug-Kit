# Retainer Task & Timer

**Tool ID:** `content.retainer.task` · **Section:** Retainers

## Purpose

Read static RetainerTask requirements and optionally calculate a completion time from a user-supplied remaining duration.

## Inputs

- **Language** and **Row ID** for the RetainerTask sheet.
- **Remaining seconds:** optional user-supplied value, 0–604,800.

## Use

Enter row/language and, if desired, remaining seconds; press **Capture**.

## Limits

Task maximum duration is static metadata, not a live venture timer. No retainer identity, inventory, other-character data, or provider state is read.
