# Observed Currency

**Tool ID:** `content.currency` · **Section:** Inventory

## Purpose

Read one selected currency item from the player's currency container.

## Inputs

- **Currency item ID:** required nonzero numeric ID.

## Use

Enter the ID and press **Capture**. Missing or unloaded container data is unavailable, not zero.

## Limits

Requires exact native compatibility and session authorization. Special currencies/caps are not inferred. No currency or item changes are made.
