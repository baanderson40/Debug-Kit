# Familiar UI Metadata

**Tool ID:** `content.familiars.ui` · **Section:** Familiars

## Purpose

Inspect metadata from already-loaded XBM familiar UI addons.

## Use

Load/open the relevant familiar UI yourself, select **Familiar UI Metadata**, then press **Capture**. No row or filter inputs.

## Limits

Requires exact native compatibility and session authorization. Reports loaded addon metadata only—not roster, stage, treasure, ownership, or card semantics. No selection or interaction is performed.
