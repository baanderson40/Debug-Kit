# Bozjan Event Evidence

**Tool ID:** `content.bozja.events` · **Section:** Content

## Purpose

Show bounded FATE evidence in supported Bozja/Zadnor territories.

## Inputs

- **Radius:** 1–200 yalms.
- **FATE row ID:** optional nonzero filter.
- **Name filter:** optional substring.
- **Numeric FATE state:** optional 0–255.

## Use

Capture while in a supported Bozja/Zadnor territory. Unsupported territories return unavailable/unsupported context rather than fabricated empty results.

## Limits

Evidence is based on supported public FATE data. Critical Engagement runtime state, CE links, and participation controls are not inferred or exposed.
