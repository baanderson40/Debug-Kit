# Housing UI Metadata

**Tool ID:** `housing.ui` · **Section:** Housing

## Purpose

Inspect metadata for already-loaded housing addons.

## Use

Open the housing UI yourself, select **Housing UI Metadata**, then press **Capture**. No row or filter inputs.

## Limits

Requires exact native compatibility and session authorization. Plot, bid, entry, tenant, and purchase state are not decoded. No chat capture or UI interaction.
