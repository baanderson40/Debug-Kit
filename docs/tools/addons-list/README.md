# Addon List

**Tool ID:** `addons.list` · **Section:** Addons & UI

## Purpose

Show bounded metadata for loaded UI addons: name, native addon ID, visibility/readiness, and available value/node counts.

## Inputs

- **Scope:** Loaded, Visible, or Focused.
- **Addon name filter:** optional text filter.

## Use

Choose a scope and optional filter, then press **Capture**. Select a row to navigate to related Values or Nodes tools; navigation does not capture automatically.

## Limits

Requires the exact native compatibility profile and enabled session authorization. Native addon IDs are not instance indexes. A missing row does not prove an addon never existed.
