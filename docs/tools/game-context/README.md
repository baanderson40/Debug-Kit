# Game Context

**Tool ID:** `game.context` · **Section:** Game State

## Purpose

Show a small snapshot of login state, territory, player readiness, position, job, level, and selected conditions. Useful for checking what context Debug Kit sees before another capture.

## Use

Select **Game Context** and press **Capture**. No inputs required.

## Limits

Read-only snapshot. No character name, character ID, object IDs, or addresses. A result is historical after capture and does not continuously update.
