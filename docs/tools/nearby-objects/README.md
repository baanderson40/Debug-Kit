# Nearby Objects

**Tool ID:** `objects.nearby` · **Section:** Objects

## Purpose

List nearby objects and their broad kind, position, distance, targetability, and bounded in-game display name.

## Inputs

- **Radius:** 1–200 yalms; default 60.
- **Kind:** any or one object category.
- **Base ID:** optional nonzero numeric filter.

## Use

Set filters, then press **Capture**. The scan spans framework updates; view the result as a snapshot, not a live list.

## Limits and privacy

At most 1,024 entries examined and 128 rows retained. Movement or slot reuse can cause omissions/duplicates. Names, positions, and territory are included in reports; raw object and owner IDs are omitted. Review before sharing.
