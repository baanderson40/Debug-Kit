# Universalis Summary

**Tool ID:** `network.universalis` · **Section:** Network

## Purpose

Fetch a public aggregated NQ/HQ market summary for one item and world or fixed data center.

## Inputs

- **Scope:** World or Data Center.
- **Item ID:** required positive ID.
- **Public world ID** for World scope, or a fixed data-center choice.
- **Allow external request for this capture:** required consent.

## Use

Review inputs and the network/privacy notice, grant consent, then press **Capture**. One fixed HTTPS GET is sent; service sees the network IP.

## Limits

External cached observations are not guaranteed current or authoritative. No individual listings, seller names, login, uploads, redirects, or automatic retries. Requests are rate-limited and bounded.
