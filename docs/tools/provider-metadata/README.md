# Provider Metadata

**Tool ID:** `providers.metadata` · **Section:** Providers

## Purpose

Summarize a fixed allowlist of optional plugins using public Dalamud installed-plugin metadata.

## Use

Select **Provider Metadata** and press **Capture**. No inputs required. This performs no IPC calls.

## Limits

Installed/loaded/version/development metadata does not prove an endpoint exists, responds, or is ready. Incomplete enumeration can leave states unknown; ambiguous duplicate matches remain ambiguous. No plugin settings or controls are accessed.
