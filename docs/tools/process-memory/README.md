# Process Memory

**Tool ID:** `system.process` · **Section:** System

## Purpose

Report bounded memory metrics for the current process, such as managed memory, working set, and private memory.

## Use

Select **Process Memory** and press **Capture**. No inputs required.

## Limits

This is a point-in-time process snapshot, not a leak diagnosis or per-plugin attribution. No process paths, handles, identities, memory trimming, or priority changes.
