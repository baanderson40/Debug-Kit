# Inventory Slots

**Tool ID:** `inventory.slots` · **Section:** Inventory

## Purpose

Inspect matching slots in normal player inventory bags.

## Inputs

- **Bag:** All or Bag 1–4.
- **Quality:** Any, NQ, or HQ.
- **Item ID:** optional nonzero filter.
- **Include empty slots:** optional.

## Use

Set filters and press **Capture**. Unloaded containers are unavailable, not empty.

## Limits

Normal bags only; no retainers, saddlebag, moves, sorting, sale, or discard. Multi-update captures are non-atomic. Item names and quantities may be included in reports; review before sharing.
