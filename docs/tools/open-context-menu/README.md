# Open Context Menu

**Tool ID:** `menus.context` · **Section:** Addons & UI

## Purpose

Inspect values from an already-open `ContextMenu` instance.

## Inputs

- **Instance index:** 1–8.

## Use

Open a context menu yourself, select **Open Context Menu**, choose the instance, then press **Capture**.

## Limits

Requires the exact native profile and session authorization. Debug Kit does not open, click, select, or invoke menu actions. Action mapping and enabled state may be unavailable; unclassified values are omitted.
