# Observed Casts

**Tool ID:** `objects.casts` · **Section:** Objects

## Purpose

Observe supported public cast data on nearby objects.

## Inputs

- **Radius:** 1–200 yalms.
- **Action ID:** optional nonzero filter.
- **Name filter:** optional substring.
- **Selected target only:** optional restriction.

## Use

Choose filters and press **Capture**. No target or action is selected or executed by Debug Kit.

## Limits

Bounded multi-update observation; cast/object state may change during the scan. Target IDs, action dispatch, and hooks are not used. Names may appear in output; review before sharing.
