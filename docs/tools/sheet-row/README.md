# Sheet Row

**Tool ID:** `sheets.row` · **Section:** Game Data

## Purpose

Read one supported row from installed game data using explicit typed field readers.

## Inputs

- **Sheet:** choose from the supported game-data sheets.
- **Language:** Client, English, Japanese, German, or French.
- **Row ID:** numeric row identifier.

## Use

Choose sheet/language, enter a row ID, and press **Capture**. Missing rows or language variants are reported unavailable.

## Limits

Only reviewed fields are shown. Referenced row IDs are not automatically followed; arbitrary reflection and broad reference traversal are not used. Text may be shortened and marked.
