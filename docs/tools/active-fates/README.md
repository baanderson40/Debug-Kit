# Active FATEs

**Tool ID:** `content.fates` · **Section:** Content

## Purpose

Observe public active FATE records near the player, with supported IDs, names, states, and bounded fields.

## Inputs

- **Radius:** 1–200 yalms.
- **FATE row ID:** optional nonzero filter.
- **Name filter:** optional substring.
- **Numeric FATE state:** optional 0–255.

## Use

Set filters and press **Capture**. Results may span framework updates.

## Limits

At most 1,024 entries examined and 128 rows retained. Missing/unreadable entries do not prove absence. No join, sync, travel, or FATE interaction controls.
