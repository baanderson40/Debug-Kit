# Duty Requirements

**Tool ID:** `content.duty` · **Section:** Content

## Purpose

Read supported static requirements from one ContentFinderCondition game-data row.

## Inputs

- **Language:** Client, English, Japanese, German, or French.
- **Row ID:** numeric duty row identifier.

## Use

Enter the row ID and language, then press **Capture**.

## Limits

Static data only. Unlock state, character average item level, rewards, launch readiness, and party-size meaning are not inferred. No duty entry or launch.
