# Occult Event Evidence

**Tool ID:** `content.occult.events` · **Section:** Content

## Purpose

Show bounded FATE evidence in the supported Occult Crescent territory.

## Inputs

- **Radius:** 1–200 yalms.
- **FATE row ID:** optional nonzero filter.
- **Name filter:** optional substring.
- **Numeric FATE state:** optional 0–255.

## Use

Capture while in Occult Crescent. Outside its supported territory the tool does not claim there are no events.

## Limits

Critical Engagement runtime state is unavailable. No event selection, travel, or interaction is performed.
