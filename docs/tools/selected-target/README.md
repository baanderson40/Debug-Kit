# Selected Target

**Tool ID:** `objects.target` · **Section:** Objects

## Purpose

Read the currently selected target's supported name, kind, position, distance, targetability, rotation, hitbox, HP, job, and level fields.

## Use

Select **Selected Target** and press **Capture**. No inputs required. Select a target in-game yourself if you want one observed.

## Limits

Debug Kit never selects or changes a target. No selected target returns a no-target result; unsupported fields remain unavailable rather than inferred. Names are included; review before sharing.
